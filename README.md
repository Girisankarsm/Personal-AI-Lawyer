# Personal AI Lawyer

Free, local RAG legal research assistant (Streamlit + FAISS + Ollama).

See **[Personal-AI-lawyer-main/README.md](Personal-AI-lawyer-main/README.md)** for setup and run steps.

```bash
cd Personal-AI-lawyer-main
pip install -r requirements.txt
ollama pull llama3.2   # optional
streamlit run app.py
```

No paid LLM APIs required.
